# Rahul Sai Challa — Portfolio

Personal portfolio for Cybersecurity Engineer & MS CS Graduate.

## Deploy

### Vercel
```bash
npm i -g vercel && vercel --prod
```

### Netlify
```bash
npm i -g netlify-cli && netlify deploy --prod --dir .
```

### GitHub Pages
1. Push to GitHub
2. Settings → Pages → Source: `main` branch → Save

## Stack
- Pure HTML / CSS / JS — no build step
- Google Fonts (Syne, Inter, JetBrains Mono)
- CSS `animation-timeline: view()` for scroll reveals
- Light/Dark theme with system preference detection
